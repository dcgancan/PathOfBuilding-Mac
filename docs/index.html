Wanted to get back into PoE with 3.29 and couldn't find a working, up-to-date PoB for Mac. Tweaked stevschmid's Mac port a bit to get it working again, so sharing it here in case it helps anyone else. Already sent the fix upstream too, so hopefully this won't be needed for long.

Install it

  1. Download the DMG using the button above.
  2. Open the downloaded file, then drag Path of Building into your Applications folder.
  3. Open Applications and double-click Path of Building.

First time opening it

macOS will block the very first launch, because this build isn't signed with a paid Apple developer certificate. Only takes a few extra clicks, once:

  1. Double-click the app. You'll get a dialog saying macOS can't verify the developer. Click Done.
  2. Open System Settings → Privacy & Security. Scroll down — you'll see a message that Path of Building was blocked. Click Open Anyway.
  3. Confirm. Click Open Anyway again in the popup (you may need your Mac password). From now on it opens normally, like any other app.

Good to know

  • Requires an Apple Silicon Mac (M1 or newer). Intel Macs aren't supported.
  • Same Path of Building your Windows friends use — same calculations, same passive tree, same PoE login for trade/imports.
  • Open source. Everything that goes into this DMG is public on GitHub.
  • Game data (skills, passive tree, items) updates itself inside the app. You only need a new DMG from this page when the app itself changes.

Something wrong?

Something works fine on Windows but not here, or something's just off on Mac (won't open, crashes, graphics glitches)? Open an issue here — happy to take a look, just mention your macOS version and chip (M1/M2/M3/M4). A build/calculation issue isn't Mac-specific, so that's better reported to the main Path of Building project instead.
